# Task 4 - Dashboard Design

## Objective

Design an interactive dashboard for business stakeholders using Tableau Public.

## Dataset

Financial Sample.xlsx

## KPIs Used

* Total Sales
* Total Profit
* Gross Sales

## Dashboard Features

* Sales Trend Analysis
* Sales by Country
* Profit by Product
* Interactive Filters
* KPI Summary Cards

## Tools Used

* Tableau Public
* Microsoft Excel

## Key Insights

* Gross Sales exceeded 127 million.
* Total Profit was approximately 16.9 million.
* Sales varied across countries, with some regions generating higher revenue.
* Paseo was one of the highest-profit products.
* Monthly sales trends showed fluctuations throughout the year.

## Files Included

* Financial Sample.xlsx
* Task4_Dashboard.twbx
* dashboard.png
* README.md

## Outcome

Created an interactive dashboard that helps business stakeholders analyze sales performance, profit trends, product performance, and country-wise sales through visual analytics.
